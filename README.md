## 👨‍💻 Sobre mí

Soy **Lcd. Gestión de la Información Gerencial de la Universidad de Guayaquil**, con formación previa como **Técnico en Aplicaciones Informáticas**.

Mi perfil combina la gestión y análisis de información con herramientas tecnológicas que permiten transformar datos en información útil para la toma de decisiones.

Tengo conocimientos en **análisis de datos, SQL, Python, ETL, Power BI, bases de datos, automatización, Machine Learning y desarrollo de aplicaciones**, además de experiencia trabajando con información operativa, sistemas ERP, facturación, inventarios y control documental.

Me especializo en desarrollar soluciones que permiten:

* 📊 Analizar y visualizar información.
* 🐍 Procesar y transformar datos con Python.
* 🗄️ Consultar y estructurar información mediante SQL.
* 🔄 Diseñar procesos ETL.
* 🤖 Automatizar tareas y procesos repetitivos.
* 📈 Crear dashboards, indicadores y KPIs.
* 🧹 Limpiar, validar y normalizar datos.
* 🌐 Desarrollar aplicaciones y herramientas web.
* ⚙️ Integrar APIs, bases de datos y diferentes sistemas.
* 🧠 Aplicar técnicas de Machine Learning a problemas de datos.
